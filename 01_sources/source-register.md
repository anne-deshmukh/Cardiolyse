# Source register

Every fact elsewhere in this repository cites a source ID from this table.

**Verification status**

| Code | Meaning |
|---|---|
| `V` | Verified: page/document read directly; quoted text checked. |
| `S` | Search-only: seen only as a web-search result summary. Content **not** checked against the page. Do not cite as fact. |
| `B` | Blocked: network policy of the research session refused the host. |
| `N` | Not found: searched for, no result. |

**Source class** (evidence weight, highest first)

1. `MFR` – manufacturer's own material (IFU, website, press release issued by Cardiolyse)
2. `REG` – official regulator / registry / legal text (EUR-Lex, EC, Fimea, Finlex, PRH, EUDAMED, patent office)
3. `SCI` – peer-reviewed or preprint scientific literature
4. `3P` – independent third party (news, hospital, partner company)
5. `AGG` – commercial data aggregator (PitchBook, CB Insights, Crunchbase…) – lowest weight; often contradictory
